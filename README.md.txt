# STM32-CAN-Vehicle-Control

基于 STM32 与 CAN 总线的分布式车身控制系统，模拟车载 ECU 间通信场景。

## 技术栈
- STM32F103C8T6
- CAN 总线（500kbps）
- ADC（车速采集）
- PWM（报警灯控制）
- UART（串口调试）
- Keil MDK

## 项目功能
- A 板：ADC 采集电位器模拟车速，通过 CAN 发送车速帧（ID=0x101）
- B 板：接收车速帧，OLED 显示车速，超速（>80km/h）触发报警灯并发送超速帧（ID=0x200）
- B 板按键发送开窗指令（ID=0x102），超速时按键被锁定
- 过滤器配置：屏蔽位模式过滤 ID，降低 CPU 负担
- 代码分层：MCAL / RTE / ASW 三层架构

## 硬件连接
- A 板：PA1（ADC）、PA11/PA12（CAN）
- B 板：PA0（PWM）、PA11/PA12（CAN）、PB0（按键）
- 两块板子通过 CAN_H、CAN_L、GND 三线互联

## 调试踩坑
1. 双板CAN通信失败，串口打印显示发送成功但接收端无数据——排查发现两块板子电源GND未连接，补接GND后通信恢复正常
2. 按键开窗无法关闭 → 原逻辑每次按键都发送开窗指令，改为 toggle 状态切换（开/关交替），问题解决
3. 过滤器配置错误导致漏帧 → 调整屏蔽位后恢复正常

## 代码结构
- can-A板/：发送端代码
- can-B板/：接收端代码
- Hardware/：硬件驱动层
- User/：应用层
